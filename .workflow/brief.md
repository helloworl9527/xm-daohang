# 项目简介（brief）

## 问题
一个"对外公开分享 + 站主自用"的内容收藏与 AI 语义检索系统：站主把网站 / 文档链接 / GitHub 公开仓库收藏起来，AI 自动抓取并用一段话总结；对外提供一个**公开展示端**（无登录，每日随机展示 3 条 + 底部提问框，任何访客可对全库提问，带次数限流）；站主则通过**登录管理端**（用户名+密码登录）管理内容与全部配置。

## 目标用户
- **站主（唯一管理员）**：添加/管理内容、改所有配置。
- **公开访客**：无需登录即可浏览每日 3 条展示 + 提问检索（受限流）。
产品定位为"公开可用 + 自己也用"；不做多用户账号体系（仅站主一个管理员账号）。

## 期望结果
- 多入口随手添加链接，AI 自动抓取 + 总结 + 打标签并入库。
- 语义关联检索：提问后返回"AI 归纳 + 命中条目列表"，严格只基于库内内容，不编造、不引入库外知识。
- 部署在公网 VPS，管理端带用户名+密码登录保护，可随时随地访问。

## 关键约束
- 部署环境：公网 VPS。
- 安全：管理端 /admin 需 用户名 + 密码登录（不启用 2FA，用户明确选择）+ 登录失败限流；公开展示端无登录；TG bot 仅响应用户 ID 白名单。
- 仅抓取公开内容（普通网页/文档 + GitHub 公开仓库），无需登录/付费墙/私有仓库凭证。
- 模型可自由配置：对话模型（LLM）与嵌入模型（Embedding）**分别独立配置**，以 OpenAI 兼容接口为主（官方厂商 / 中转 / 本地 Ollama·vLLM 均可）。
- 规模：约几百条（个人精选，非批量海量）。

## 非目标（v1）
- 飞书 bot 入口（后续迭代）。
- Agent 接入（MCP Server / 开放 API 供外部 AI 调用添加内容）（后续迭代）。
- 多用户 / 账号注册 / 多租户。
- 抓取需要登录/付费/私有仓库的内容。

## 交付形态
自部署项目（跑在用户自己的公网 VPS 上）。
