# 导航站增强 UI 原型

这是与正式 Next.js 源码隔离的静态交互原型，仅用于选择信息架构和交互方向。界面中的站点、分类、数量、AI 建议和保存结果均为明确的原型数据，不代表后端已经实现。

## 运行

```bash
cd .workflow/ui-prototype-nav-enhancement
python3 -m http.server 4177
```

浏览器打开 `http://127.0.0.1:4177/`。

## 可验证交互

- 默认展示已选定的 C 工作台；A/B 仅保留为对比。可切换公开首页/分类管理、中文/英文和页面状态。
- 点击分类锚点，滚动并短暂强调目标分组。
- 首页无 hero、无每日轮换、无顶部整块搜索区；紧凑关键词搜索框位于“目录”标题行右侧，目录区不显示 eyebrow、副标题或搜索说明，底部“向收藏库提问”AI 问答框保持原位。
- 使用“关键词找站点”体验字面匹配、加载、结果、无结果和清空恢复；它与底部 AI 问答互不替代。
- 公开卡片以新标签打开，带 `target="_blank" rel="noopener nofollow"`。
- 管理端触发 F202a 补充建议或 F202b 全量重拟，逐项接受/忽略/编辑 diff，再二次确认应用和可选重跑。
- 管理端仍支持分类重命名、删除二次确认和条目人工分类。
- 管理端条目分类选择器支持手动改分类，并显示保存反馈。
